Send colored text in Discord

        
    
          
  1. Write your message in the editor. It works like any other text box.
    2. 
          
  2. Select some text and pick a color, a style or an effect from the panel.
    3. 
          
  3. Press Copy for Discord and paste into any channel or DM. It arrives as a code block in your colors.
    4. 
        


        
Questions

        

          

            Why do my friends see plain text?
            
Colors only show inside code blocks on Discord's desktop app and in the browser. Mobile support has lagged behind for years, and custom RGB colors only rolled out in October 2026, so people on older app versions may see plain text or just the eight classic colors.

          

          

            Why do the classic colors look different for some people?
            
The eight classic colors follow each reader's theme, so red on Light is a different red than on Onyx. Custom colors are fixed and look the same everywhere. Switch the preview between Light, Ash, Dark and Onyx to check your message.

          

          

            How long can a message be?
            
2,000 characters, or 4,000 with Nitro. The color codes count too, so effects that color every letter fill a message quickly. The counter under the editor shows the total, and Show codes shows exactly where the characters go.

          

          

            Can I edit a message I already sent?
            
Yes. Copy the message in Discord and paste it into the editor, the colors come back. Import, in the menu at the top right of the editor, also reads bot strings written with \u001b escapes and colored terminal output.

          

          

            Can I use this in a bot?
            
Open the arrow next to Copy for Discord and choose discord.js, discord.py, JDA, a webhook body or a plain escaped string. Each one is ready to paste into your code.

          

          

            Is my text sent anywhere?
            
No. Everything runs in your browser and your draft is saved on this device only. A share link carries the message inside the link itself, so nothing gets uploaded.

          

          

            Is this made by Discord?
            
No. Chromacord is an unofficial, open source tool. It is not affiliated with or endorsed by Discord.

          

        

      


      

        
How the codes work

        
Discord colors text inside a code block marked ansi. Every style change is the escape character (ESC, U+001B) followed by a code. Chromacord writes them for you, this is what they mean.

        

          
CodeDoesExample

          
            
ESC[0mReset everythingPlain

            
ESC[1mBoldBold

            
ESC[3mItalicItalic

            
ESC[4mUnderlineUnder

            
ESC[9mStrikethroughStruck

            
ESC[30m to ESC[37mClassic text colorsColors

            
ESC[40m to ESC[47mClassic backgrounds      

            
ESC[38;2;R;G;BmAny text colorCustom

            
ESC[48;2;R;G;BmAny backgroundCustom

          
        

        
Codes combine with semicolons. ESC[1;4;38;2;124;134;255m is bold, underlined indigo. A message starts with ```ansi on its own line and ends with ```.
